## Context
The Android build failed because the Android Gradle Plugin (AGP 8.9.1) was below Flutter's minimum
(8.11.1), and later because Kotlin and Gradle were also incompatible. After the build worked, I started
Part 1: `Note.fromFirestore` and `Note.toFirestore` in `lib/models/note.dart`. Several prompts were
needed over the session; two are shown below.

```

build apk --debug, fix only the error that appears (Kotlin, Gradle wrapper, minSdk, google-services).

else null) and toFirestore (title, body, createdAt: FieldValue.serverTimestamp(), no id).

```

## Result
**Build fix** (a chain of errors, each fixed in turn):
- `android/settings.gradle.kts`: AGP `8.9.1` -> `8.11.1`; Kotlin `2.1.0` -> `2.2.20`
  (Flutter's error asked for at least 2.2.20).
- `android/gradle/wrapper/gradle-wrapper.properties`: `gradle-9.7.1-bin.zip` -> `gradle-9.5.0-bin.zip`.
- `android/gradle.properties`: `-Xmx8G -XX:MaxMetaspaceSize=4G` -> `-Xmx3G -XX:MaxMetaspaceSize=1G`
  (the Gradle daemon disappeared during a build, so I lowered the memory use).
- `flutter build apk --debug` now succeeds.

**Part 1** (`lib/models/note.dart`):
- `fromFirestore` reads `title` and `body`, throws `FormatException` with a clear message if either is
  not a `String`, and converts `createdAt` with `.toDate()` only when it is a `Timestamp` (otherwise `null`).
- `toFirestore` returns `title`, `body` and `createdAt: FieldValue.serverTimestamp()`, with no `id` field.
- I removed the `ignore_for_file: unused_import` line, as the file asked, because the import is now used.

## Rejected suggestion(s)
- **AGP 9.x:** rejected. It needs the new Android DSL and breaks the Flutter Gradle plugin.
- **Gradle 8.14.3 (`-all` zip):** tried and rejected. The installed JDK is 25, which Gradle 8.14.3
  does not support; Gradle 9.1 or newer is required. I used 9.5.0 because Gradle 9.6 and later
  removed an internal API that AGP 8.x needs.
- **`data['title'] as String`:** rejected for Part 1. A bad value would throw `TypeError`, but the lab
  requires a `FormatException`.

**Result:** `signIn` and `signUp` call `_auth.signInWithEmailAndPassword` /

**Verification:** `flutter test` went from +3 -13 to +8 -8. All four Part 2 tests pass; the remaining

notes_repository.dart, note.dart and the NotesRepository tests. Implement watchNotes (orderBy createdAt

**Result:** `watchNotes` uses the given `_notes(uid)` helper, `.orderBy('createdAt', descending: true)`,

## What I learned
Build errors can come one after another: AGP, Gradle, Java and Kotlin versions must all fit together, so
read each error and fix only that one. A `FormatException` for bad data is clearer than a type-cast crash.
